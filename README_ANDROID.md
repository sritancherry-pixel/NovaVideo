# NovaVideo AI — Android-ready package

This package wraps the NovaVideo V1 mobile web UI in Capacitor so it can be compiled into a real Android APK.

- App ID: `ai.novavideo.app`
- App name: `NovaVideo AI`
- Video generation: Google Veo 3.1 through the included Node.js backend
- API key: server-side only
- Backend URL: `public/config.js`

See `ANDROID_BUILD.md` for the exact build commands.
